# All Files on this GitHub Repository (MAIOS Project)

Format file khusus sistem kustom ini menggunakan ekstensi **`.maios`** dan didukung sepenuhnya dengan struktur 100% C++ serta modul pendukung lainnya.

## Daftar File dan Direktori Proyek:

1. **Folder H (Header C++)**:
   - `maios_core.h`: Konfigurasi dan struktur inti sistem MAIOS[span_0](start_span)[span_0](end_span).
   - `maios_utils.h`: Deklarasi utilitas manajemen file dan komponen[span_1](start_span)[span_1](end_span).
   - `maios_app_support.h`: Struktur data dukungan aplikasi sistem[span_2](start_span)[span_2](end_span).

2. **Folder CPP (Implementasi C++)**:
   - `vecol.cpp`: Logika utama modul Vecol berbasis C++ murni.

3. **Folder Java**:
   - `MaiosMain.java`: Inisialisasi modul pendukung berbasis Java[span_3](start_span)[span_3](end_span).

4. **Folder Root / Aplikasi**:
   - Arsip file ZIP utama proyek yang bisa langsung di-download pengguna.
   - Folder `app` yang mencakup file APK esensial seperti **Magisk** dan **Aurora Store**.
